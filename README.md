# SideStore Anisette 服务器列表

供 SideStore 0.5.8 及以上使用的自定义 Anisette 服务器列表。列表中只有一台 v3 服务器：`anisette-v3`。

列表地址：

https://raw.githubusercontent.com/lxsw990116-dev/sidestore-anisette-list/cursor/sidestore-servers-json-120e/servers.json

## 使用方法

1. 打开 SideStore，进入「设置」。
2. 滑到底部，点「Anisette Servers」。
3. 点列表 URL，替换为上面的地址。
4. 点「Refresh Servers」。
5. 在刷新后的列表中选择 `anisette-v3`。

服务器地址为 `https://anisette-v3-avwv.onrender.com`。免费实例闲置约 15 分钟后会休眠，第一次请求可能要等它唤醒。
